# Pathfinding Lab: Dijkstra vs A*

## Goal
An interactive browser page that explains shortest-path search. Two grids run Dijkstra and A* side by side on the same walls, with live editing, progressive path reveal, and a plain-language explanation of each step.

## Category
Learning / Coding & Development.

## Tech stack
- One static HTML file (inline CSS and JS), canvas rendering, no dependencies, no network calls.
- Target host: GitHub Pages (public).

## Key files
- `index.html`: the whole app (served by GitHub Pages from the repo root).

## How Claude should help
- Keep it a single dependency-free file at the repo root so GitHub Pages can serve it as-is.
- Test changes headless in Chrome before reporting them done.
- Publishing to GitHub Pages is outward-facing: confirm before creating a repo or pushing.
